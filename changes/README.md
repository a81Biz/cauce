# changes — un directorio por PT

**Vacío.** Este archivo sostiene el espacio (`SUITE-R32`).

Todo el estado de trabajo de un PT vive en `changes/PT-NNN-slug/`: `intake.md` (PHASE 1, lo
firma el humano), `context.md`, `strategy.md`, `design.md`, `tasks.md`, `traceability.md`,
`bitacora.md`.

El identificador sale de `docs/implementation/REGISTRY.json` y de ningún otro sitio
(`SUITE-R08`, `LEX-R06`). Contar directorios aquí para deducir el siguiente número está
prohibido.

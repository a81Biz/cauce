# PT-064 — Cambios de especificación   `PHASE 4` · `FDGE-R22`

**Ninguno.**

Esta tarea no introduce vocabulario, no modifica reglas y no toca `LEXICON`, `RULES` ni
`EXECUTION-MODES`. Cambia **de dónde salen las entradas** de tres cifras que ya existían.

Se declara igualmente, y con esta frase, porque `FDGE-R22` pide declarar el cambio **antes** de
hacerlo — y «no hay cambio» es una declaración, no una omisión. Un `spec-changes.md` ausente y uno
que dice «ninguno» se leen igual en un listado y significan cosas distintas.

**Lo que se apoya en lo ya declarado:**

- `LEXICON` §6.5f (`PT-061`) — las personas y sus identidades de git.
- `LEXICON` §6.5c (`PT-058`) — `SIN EVALUAR` para lo que no se puede repartir.
- `LEXICON` §6.5d (`PT-059`) — el precedente y el techo.

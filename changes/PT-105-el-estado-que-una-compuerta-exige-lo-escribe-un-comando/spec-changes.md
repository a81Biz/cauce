# Cambios de especificación — `PT-105`

**Ninguna regla cambia.**

| | |
|:---|:---|
| Reglas nuevas | ninguna |
| Reglas modificadas | ninguna |
| Reglas derogadas | ninguna |
| `RIGE_DESDE` | no aplica |
| Vocabulario nuevo | ninguno — `DONE` ya está en `LEXICON` §5.1 |

Lo que cambia es **quién escribe un estado que ya era obligatorio**. `FDGE-R34` exigía `DONE`
para `G4` desde antes; lo que faltaba era el comando que lo pusiera.

No hace falta `RIGE_DESDE`: no se añade una obligación nueva que pudiera juzgar lo anterior. La
obligación existía y lo que se añade es la forma de cumplirla.

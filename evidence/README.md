# evidence — la prueba de que algo funciona

**Vacío.** Este archivo sostiene el espacio (`SUITE-R32`).

Una carpeta por PT: `evidence/PT-NNN/` con `manifest.json` —que mapea cada `AC-nn` a un
artefacto real presente en disco (`FDGE-R23`)— más `self-review.md` y lo que corresponda al
tipo de cambio.

capturas de pantalla a un PT de backend es ceremonia, no evidencia. En este repositorio, que
no tiene interfaz, lo que corresponde es salida de ejecución de los verificadores y del
`selftest`.

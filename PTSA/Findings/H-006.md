# H-006 — CLAUDE.md miscuenta las herramientas y los comandos del binario

> `D4` · **BAJA** · tipo `BUG` · estado `VALIDATION_PENDING`

## Qué se observó

```
CLAUDE.md:59   «── HERRAMIENTAS ─── 15, y ninguna es opcional ───»
ls docs/methodology/tools/ | wc -l   ->  16

CLAUDE.md      «bin/cauce.mjs   El binario publicado: install · verify · compare · core»
comandos reales                      ->  install verify compare core start regla version   (7)
```

está mal es la que el agente carga en cada sesión.

afirmación falsa en un documento de orientación, y `FND-R12` ya declara que `CLAUDE.md` no es la
autoridad sobre el repositorio.

Se registra porque el marco no admite «es sólo documentación»: una cifra escrita a mano que nadie
recalcula es exactamente el material del que están hechos `H-003` y `H-007`.

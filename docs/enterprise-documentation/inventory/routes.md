# inventory/routes — no aplica

> Foundation `PHASE 5` · 2026-08-19 · suite 9.0.0 · segunda ejecución

**Este sistema no tiene rutas.** No hay servidor HTTP, ni router, ni interfaz de usuario: cauce
es un paquete npm con un binario de línea de comandos y un cuerpo de documentos.

Lo más parecido a una superficie de entrada son los cinco comandos de `bin/cauce.mjs`, y están
enumerados en [../03-TRD.md](../03-TRD.md#el-binario) con su contrato de códigos de salida.

Este archivo existe para que la ausencia sea **declarada** y no se confunda con un inventario
que nadie hizo (`SUITE-R32`): git no versiona directorios vacíos, y «no aplica» y «no se miró»
tienen que poder distinguirse.
